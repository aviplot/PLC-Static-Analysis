# P0 — Corpus harvest

Goal: collect real-world PLC code for all four target languages before any grammar work, so the
grammars are designed against what engineers actually export, not only against the spec.

## Deliverables
- `tools/corpus-harvester/` — standalone Python 3 CLI (stdlib only; not shipped with the product).
- `corpus/MANIFEST.csv`, `corpus/STATS.md`, `corpus/SOURCES.md` (generated, committed).
- `corpus/external/` — raw harvested files (git-ignored).

## Pipeline
1. **discover** — candidate repositories from
   - GitHub code search (`/search/code`) per file type: `.TcPOU .TcDUT .TcGVL .TcIO .plcproj .tsproj`,
     `.scl`, `.db`+`DATA_BLOCK`, `.udt`+`END_TYPE`, `.L5X .L5K`, `.st`+`END_VAR`, PLCopen `tc6_0201` XML.
     Each query is split by file-size ranges when it exceeds the 1000-result API cap.
   - GitHub repo search: topics and keywords (`twincat codesys plc structured-text iec-61131-3
     tia-portal studio5000 plcopen oscat`).
   - GitLab public project search (`/api/v4/projects?topic=` / `?search=`) as a second source.
2. **fetch** — per repo, a partial shallow clone (`--depth 1 --filter=blob:none --no-checkout`),
   list the tree, check out only candidate paths + root LICENSE/COPYING, classify by content,
   keep matches under `corpus/external/<host>/<owner>/<repo>/`, delete the clone.
   Only the matching blobs are downloaded, which keeps bandwidth and disk use low.
3. **build** — deduplicate by SHA-256 (first repo in discovery order wins; duplicates are deleted),
   write MANIFEST/STATS/SOURCES.

## Content filters (noise rejection)
| Extension | Kept only if |
|---|---|
| `.TcPOU/.TcDUT/.TcGVL/.TcIO` | `<TcPlcObject` root |
| `.plcproj` / `.tsproj` | MSBuild `<Project` / `<TcSmProject` |
| `.st` | ≥ 2 distinct ST block keywords (`END_VAR`, `END_IF`, `FUNCTION_BLOCK`, …) and no Smalltalk markers |
| `.scl` | an SCL block keyword + matching `END_…` |
| `.db` | `DATA_BLOCK` … `END_DATA_BLOCK` (rejects SQLite) |
| `.udt` | `TYPE` … `END_TYPE` |
| `.L5X` / `.L5K` | `<RSLogix5000Content` / `IE_VER` or `CONTROLLER` |
| `.xml` | PLCopen `tc6_0201` (or `tc6_0200`) namespace + `<project` |

## Robustness
- Auth from `GITHUB_TOKEN` (optional `GITLAB_TOKEN`). Back off on 403/429 using `Retry-After` /
  `X-RateLimit-Reset`, exponential otherwise.
- Checkpoint `corpus/external/.harvest-state.json` (atomic writes); every stage resumes.
- Disk guards: per-file size cap, corpus budget, minimum free space.
- Never executes harvested content; clones with `GIT_TERMINAL_PROMPT=0`, LFS smudge off.

## License policy (enforced in code)
- `fixture-ok`: MIT, MIT-0, BSD-2/3-Clause, 0BSD, Apache-2.0, Unlicense, CC0-1.0.
- `local-only`: everything else, including `NOASSERTION`. Recorded per file in the manifest.
- Nothing from `corpus/external/` is committed; `.gitignore` enforces it.

## Done when
Harvester runs end to end; MANIFEST/STATS exist; real code exists for all four languages, or
STATS.md documents the gap and the synthetic-file plan.
