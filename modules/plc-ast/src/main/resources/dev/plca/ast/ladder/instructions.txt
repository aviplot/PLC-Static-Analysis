# Rockwell Logix 5000 instructions: operand roles for lowering and effects.
# Source: Logix 5000 Controllers General Instructions Reference Manual (1756-RM003); motion operands from MOTION-RM002.
# Chosen by repo count in the corpus (docs/grammar/rockwell.md §4). Lines ending in '?' are not checked against the
# manual text yet (TODO(verify-format)).
#
# Format: MNEMONIC KIND ROLE...
#   KIND   in      input: ANDs a term onto the rung condition
#          out     output: runs when the rung condition is true
#          always  output that runs every scan with the rung condition as its input (timers, counters, one-shots)
#   ROLE   r read, w write, rw read and write, inst instance structure (read and written), name (a word that is not a
#          tag: class/attribute names, modes), routine, label, expr (an expression), disp (display value: not lowered),
#          n (operand count), jsr (JSR/SBR-style parameters: the first n are inputs, the rest returns).
#          A trailing '*' repeats the role for all further operands.
